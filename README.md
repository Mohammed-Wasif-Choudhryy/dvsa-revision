# UK DVSA High-Yield Master Revision & 3D Hazard Simulator

Live Web App: **[https://mohammed-wasif-choudhryy.github.io/dvsa-revision/](https://mohammed-wasif-choudhryy.github.io/dvsa-revision/)**

A high-yield interactive revision system and 3D hazard simulator for the UK DVSA driving theory test.

## Features
- **High-Yield Theory Modules**: Core topics, rules, and question banks.
- **Interactive 3D Hazard Simulator**: Simulated driving scenarios with reaction testing.
- **Formula & Stopping Distance Visualizer**: Real-time stopping distances at various speeds and weather conditions.
- **Motorway Studs & Road Signs Mastery**: Interactive guides for motorway lighting studs, road markings, and UK signs.
- **Mobile-Responsive**: Optimized for smartphones, tablets, and desktop browsers.

## How to use on Mobile
1. Open [https://mohammed-wasif-choudhryy.github.io/dvsa-revision/](https://mohammed-wasif-choudhryy.github.io/dvsa-revision/) on Safari (iOS) or Chrome (Android).
2. Tap **Share** (iOS) or the **three dots menu** (Android) and choose **"Add to Home Screen"**.
3. It will launch like a native full-screen app!
